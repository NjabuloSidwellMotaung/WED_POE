PAGE-BY-PAGE NOTES
--------------------------------------------------------------------
Home (index.html)
  Header/nav > auto-rotating photo carousel > slideshow thumbnail
  strip (links to Projects) > "Exceptional Quality" business copy >
  services grid (8 trades) > CTA band > footer.

About (about.html)
  Company story it is all about the company how it strated and all you need to know text,
  plus a why-work-with-us section.

Projects (projects.html)
  Full gallery of the 8 real uploaded project photos, each tagged
  by trade (Electrical, Roofing, Painting, Tiling, Paving, etc).

Admin (admin.html)
  Front-end-only mockup of an owner login and a gallery upload
  form. NOTHING IS FUNCTIONAL YET -- see "Admin login" below.

Get a Quote (quote.html)
  A form (name, phone, area, service, details) that on submit
  builds a WhatsApp message and opens wa.me with it pre-filled.
  No backend needed -- works straight off the file system.


ADMIN LOGIN -- STILL A MOCKUP
--------------------------------------------------------------------
